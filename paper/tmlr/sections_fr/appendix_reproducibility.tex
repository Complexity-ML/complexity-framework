\section{Liste de contrôle pour la reproductibilité}

Le package anonyme contient :
\begin{itemize}
    \item un mini-framework autonome implémentant W/R/V contextuel, GQA apparié, le chemin feed-forward partagé à objets lexicaux/micro-experts, l'entraînement, l'évaluation et les tests ciblés, sans dépendance au framework de recherche des auteurs ;
    \item les configurations JSON réalisées et CSV par étape pour les seeds 42--44, plus les deux ablations exploratoires à la seed 42 ;
    \item paramètres, budgets, optimiseur, mode numérique, backend et commits source ;
    \item la révision, le chemin et le SHA-256 du shard FineWeb-Edu ;
    \item un résumé lisible par machine dont dérivent les tableaux~\ref{tab:h200-controlled} et~\ref{tab:h200-throughput} ;
    \item les tests de causalité, formes groupées, RoPE, lexical-off, projection fusionnée et cache full/incrémental.
\end{itemize}

Le shard est \texttt{sample/10BT/000\_00000.parquet}, révision \texttt{87f09149ef4734204d70ed1d046ddc9ca3f2b8f9}, SHA-256 \texttt{b1ba7b2ce4cb5ea6ef42dca40263eabb85f37700d01693a68e9b30a31d78e871}. Chaque run traite 32~768 tokens par étape pendant 3~052 étapes ; l'évaluation finale utilise 32 batches déterministes à l'étape 3~000.

Le ZIP exclut historique Git, credentials, adresses cloud, noms d'hôtes, chemins locaux, logs, checkpoints et shard de 2,15~Go. Les checkpoints ne sont pas nécessaires à la comparaison rapportée ; l'identité figée du dataset permet son téléchargement exact. Le ZIP extrait et les métadonnées PDF sont scannés avant soumission.
