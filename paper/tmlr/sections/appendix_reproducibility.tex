\section{Reproducibility Checklist}

The anonymous review package contains:
\begin{itemize}
    \item a standalone mini-framework implementing contextual W/R/V, matched GQA, the shared lexical-object/micro-expert feed-forward path, training, evaluation, and targeted tests, with no dependency on the authors' research framework;
    \item realized JSON configurations and per-step CSV metrics for GQA and W/R/V at seeds 42--44, plus the two exploratory seed-42 ablations;
    \item exact model parameter counts, token budgets, optimizer fields, numerical mode, backend information, and source commits;
    \item the pinned FineWeb-Edu revision, shard path, and SHA-256;
    \item a machine-readable summary from which Tables~\ref{tab:h200-controlled} and~\ref{tab:h200-throughput} are generated;
    \item unit tests for causality, grouped shapes, RoPE, lexical-off behavior, fused projection equivalence, and full/incremental cache behavior.
\end{itemize}

The archived shard is \texttt{sample/10BT/000\_00000.parquet} from FineWeb-Edu revision \texttt{87f09149ef4734204d70ed1d046ddc9ca3f2b8f9}; its SHA-256 is \texttt{b1ba7b2ce4cb5ea6ef42dca40263eabb85f37700d01693a68e9b30a31d78e871}. Every run processes 32,768 tokens per step for 3,052 steps. Evaluation uses 32 deterministic held-out batches at step 3,000.

The submission ZIP excludes Git history, credentials, cloud addresses, hostnames, local user paths, transient logs, model checkpoints, and the 2.15GB dataset shard. Checkpoints are not required for the reported comparison; the pinned dataset identity permits exact retrieval. The final extracted ZIP and PDF metadata are scanned for identifying strings before submission.
