\section{Experimental Design}
\label{sec:experiments}

\subsection{Controlled comparison}

The primary experiment compares dense GQA with contextual W/R/V attention. Both models use ten layers, hidden size 384, eight read/query heads, two shared write/value or key/value heads, and the same lexical-object micro-expert feed-forward path. GQA has 98,179,844 parameters and W/R/V has 98,195,204 (a 0.016\% difference). The W/R/V lexical write residual is fixed to zero and skipped, while per-head RMS normalization of R and W remains active.

\subsection{Data, tokenizer, and budget}

All six controlled runs use the 200,019-entry \texttt{o200k\_base} tokenizer and FineWeb-Edu \texttt{sample-10BT}, sequence length 2,048, BF16, batch size 16, and seeds 42--44. Each run performs 3,052 steps, or exactly 100,007,936 training tokens. A deterministic 5\% document stream is reserved for evaluation and excluded from training. The final estimate averages 32 batches (1,048,576 tokens) and is taken at step 3,000. The archived dataset shard is pinned to revision \texttt{87f0914} with SHA-256 \texttt{b1ba7b2c...d78e871}.

Both conditions use AdamW, peak learning rate $4\times10^{-4}$, weight decay 0.1, identical warmup/decay, chunked exact-vocabulary loss, eager execution, and the same H200 software stack. Compilation is disabled for both because a tied lexical-table path produced non-finite gradients under the tested compiler stack; eager execution remained finite.

\subsection{Metrics and throughput}

We report held-out next-token cross-entropy and training throughput separately. Throughput for each run is the median of finite logged points from step 500 onward after excluding points below 80k tokens/s caused by evaluation, checkpoint, or network stalls. We report the mean of the three run medians. The paired loss difference is W/R/V minus GQA for the same seed. With $n=3$, we provide the sample standard deviation and a two-sided 95\% Student-$t$ interval, but do not treat it as evidence of significance.

\subsection{Archived evidence}

Each controlled run has a realized JSON configuration, per-step CSV, final checkpoint, source commit, and SHA-256 manifest. The exact 2.15GB FineWeb-Edu Parquet shard is archived for offline reevaluation. Historical H100 WVR and W/R/V path runs use different protocols and appear only as descriptive development evidence; they are not pooled with H200 results.

\subsection{Hardware and numerical checks}

Controlled runs use one NVIDIA H200 with PyTorch SDPA permitting FlashAttention dispatch. FP32 unit tests cover W/R/V causality, padding masks, grouped head shapes, RoPE, cache behavior, fused R/W/V projection equivalence, lexical-off invariance, and full/incremental equivalence. The W/V cache grows with prefix length, like a grouped KV cache; W/R/V is not presented as fixed-state or attention-free.
